# 3. Current Evaluation Framework

## 原文

The automatic evaluation framework proposed for ActivityNet Captions has been widely utilized for the DVC task. Let $\mathcal{G}$ be a set of manually-generated reference captions for a video and $\mathcal{P}$ be a set of captions generated by a system. We denote $g$ as a reference caption and $p$ as a caption generated by the system.

Each caption has a proposal that indicates a time span of an event that appears in a video. Here, the IoU between $g$ and $p$ is defined as follows:

$$\text{IoU}(g, p) = \max\left(0, \frac{\min(e(g), e(p)) - \max(s(g), s(p))}{\max(e(g), e(p)) - \min(s(g), s(p))}\right)$$

where functions $s(\cdot)$ and $e(\cdot)$ return the start and end time of the proposal, respectively. Here, a set of reference captions whose IoU exceeds a specific threshold, $\tau$, for $p$ is defined as follows:

$$G_{p,\tau} = \{g \in \mathcal{G} | \text{IoU}(g, p) \geq \tau\}$$

When $G_{p,\tau} = \emptyset$, i.e., $p$ does not have any $g$ that exceeds a specific threshold, we add a random string to $G_{p,\tau}$ as a member instead of the caption as a penalty. Finally, a set of generated captions, $\mathcal{P}$, is evaluated on the basis of a set of reference captions, $\mathcal{G}$, by the following equation:

$$E(\mathcal{G}, \mathcal{P}, \tau) = \frac{\sum_{p \in \mathcal{P}} \sum_{g \in G_{p,\tau}} f(g, p)}{\sum_{p \in \mathcal{P}} |G_{p,\tau}|}$$

where function $f(\cdot, \cdot)$ denotes an evaluation metric such as METEOR, BLEU, or CIDEr. In this paper, we use METEOR as $f(\cdot, \cdot)$ since ActivityNet Challenge use it as its official metric. In most cases, the final evaluation score was computed as the average for $\tau = 0.9, 0.7, 0.5, 0.3$.

Consider, for example, that IoUs between $\mathcal{G}$ and $\mathcal{P}$ are given as in Figure 1. When we set $\tau$ to 0.5, we obtain the following: $G_{p_1,0.5} = \{g_1, g_4\}$, $G_{p_2,0.5} = \{g_3, g_4\}$, $G_{p_3,0.5} = \{g_2, g_4\}$, $G_{p_4,0.5} = \{g_1, g_3, g_4\}$, $G_{p_5,0.5} = \{g_2, g_3\}$. Then, we compute METEOR scores for the eleven matched pairs between $g$ and $p$, and average the scores.

## 译文

为 ActivityNet Captions 提出的自动评估框架已被广泛用于 DVC 任务。设 $\mathcal{G}$ 为视频的人工生成参考描述集合，$\mathcal{P}$ 为系统生成的描述集合。我们用 $g$ 表示参考描述，用 $p$ 表示系统生成的描述。

每个描述都有一个提案，指示视频中出现的事件的时间跨度。这里，$g$ 和 $p$ 之间的 IoU 定义如下：

$$\text{IoU}(g, p) = \max\left(0, \frac{\min(e(g), e(p)) - \max(s(g), s(p))}{\max(e(g), e(p)) - \min(s(g), s(p))}\right)$$

其中函数 $s(\cdot)$ 和 $e(\cdot)$ 分别返回提案的开始和结束时间。这里，对于 $p$，IoU 超过特定阈值 $\tau$ 的参考描述集合定义如下：

$$G_{p,\tau} = \{g \in \mathcal{G} | \text{IoU}(g, p) \geq \tau\}$$

当 $G_{p,\tau} = \emptyset$ 时，即 $p$ 没有任何超过特定阈值的 $g$，我们添加一个随机字符串到 $G_{p,\tau}$ 作为惩罚，而不是描述。最后，生成描述集合 $\mathcal{P}$ 基于参考描述集合 $\mathcal{G}$ 通过以下公式进行评估：

$$E(\mathcal{G}, \mathcal{P}, \tau) = \frac{\sum_{p \in \mathcal{P}} \sum_{g \in G_{p,\tau}} f(g, p)}{\sum_{p \in \mathcal{P}} |G_{p,\tau}|}$$

其中函数 $f(\cdot, \cdot)$ 表示评估指标，如 METEOR、BLEU 或 CIDEr。在本文中，我们使用 METEOR 作为 $f(\cdot, \cdot)$，因为 ActivityNet Challenge 将其用作官方指标。在大多数情况下，最终评估分数是 $\tau = 0.9, 0.7, 0.5, 0.3$ 的平均值。

例如，考虑 $\mathcal{G}$ 和 $\mathcal{P}$ 之间的 IoU 如图 1 所示。当我们设置 $\tau$ 为 0.5 时，我们得到：$G_{p_1,0.5} = \{g_1, g_4\}$，$G_{p_2,0.5} = \{g_3, g_4\}$，$G_{p_3,0.5} = \{g_2, g_4\}$，$G_{p_4,0.5} = \{g_1, g_3, g_4\}$，$G_{p_5,0.5} = \{g_2, g_3\}$。然后，我们计算 $g$ 和 $p$ 之间十一个匹配对的 METEOR 分数，并对分数进行平均。

## 理解与批注

### IoU 计算示意

```
Reference:  |----[g]------|
Generated:      |---[p]---|
                ↑ overlap ↑

IoU = overlap / union
```

### 评估流程

```
Step 1: 对每个生成的 p，找所有 IoU > τ 的参考 g
Step 2: 计算所有匹配对的 METEOR
Step 3: 平均

问题：一个 p 可以匹配多个 g！
```

### 示例

IoU 矩阵 (τ = 0.5):

|    | p1  | p2  | p3  | p4  | p5  |
|----|-----|-----|-----|-----|-----|
| g1 | 0.7✓| 0.1 | 0.4 | 0.9✓| 0.1 |
| g2 | 0.2 | 0.3 | 0.5✓| 0.4 | 0.5✓|
| g3 | 0.4 | 1.0✓| 0.3 | 0.7✓| 0.8✓|
| g4 | 0.8✓| 0.7✓| 0.6✓| 1.0✓| 0.1 |

匹配对：
- $G_{p_1} = \{g_1, g_4\}$ → 2 对
- $G_{p_2} = \{g_3, g_4\}$ → 2 对
- $G_{p_3} = \{g_2, g_4\}$ → 2 对
- $G_{p_4} = \{g_1, g_3, g_4\}$ → 3 对
- $G_{p_5} = \{g_2, g_3\}$ → 2 对

**总共 11 对**，计算 METEOR 并平均
