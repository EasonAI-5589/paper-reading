# 4. Experiment

## 📌 预览
实验分三部分：仿真（RLBench 10 任务）+ 消融（4 组设计选择）+ 真机（10 任务，4 类平台）。

---

## 4.1 仿真实验（RLBench）

### 设置
- **环境**：RLBench（CoppeliaSim），Franka Panda，单前视角
- **数据**：每任务 100 条 demo
- **评估**：每任务 20 次 rollout × 3 随机种子，报告均值±方差

### 主要结果（Table 1）

| 方法 | 参数量 | 成功率 | 推理速度 |
|------|--------|--------|----------|
| **LaST₀（ours）** | 3.3B | **82%** | **15.4 Hz** |
| HybridVLA | 7B | 74% | - |
| π₀.₅ | 3B | 65% | 13.8 Hz |
| CoT-VLA | - | - | 1.1 Hz |
| CogACT | 7B | 61% | - |
| OpenVLA | 7B | - | - |

> 💡 **关键对比**：
> - vs HybridVLA（7B）：3.3B 参数反超 7B，+8%
> - vs π₀.₅（3B）：同量级参数，+17%
> - vs CoT-VLA（显式 CoT）：速度快 **14×**（15.4 vs 1.1 Hz）
> - 10 任务中 7 个拿第一，一致性强

## 4.2 消融实验（4 组）

### (a) Latent CoT 模态的重要性

| 配置 | 成功率 |
|------|--------|
| 仅视觉 z^v | 74% |
| 仅点云 z^p | 76% |
| 仅本体 z^s | 75% |
| 三模态全用 | **82%** |

> 💡 **结论**：三种模态各自都有效，联合使用有额外增益。说明几何/语义/本体信息是互补的，缺一不可。

---

### (b) 每模态 token 数量

| Token 数/模态 | 成功率 |
|--------------|--------|
| 0（无 latent） | 68% |
| **1** | **82%** |
| 2 | ~82% |
| 4+ | ~82% |

> 💡 **结论**：1 个 token 已经够了，增加 token 数无收益。Average pooling 的压缩足以编码关键物理信息，更多 token 只增加计算开销。

---

### (c) 时序覆盖步数

| 未来步数 H | 成功率 |
|-----------|--------|
| 0 | 68% |
| 1 | 74% |
| 2 | 78% |
| **4** | **82%** |
| 6+ | ~82% |

> 💡 **结论**：时序越长越好，直到 4 步饱和。说明 latent CoT 需要足够的时间跨度来建立因果依赖，4 步已能覆盖大多数操作的关键阶段。

---

### (d) 快慢频率比

| 训练/推理比 | 成功率 |
|------------|--------|
| 1:1（单一） | 75% |
| 1:2（单一） | 77% |
| 1:4（单一） | 79% |
| 1:8（单一） | 74% |
| **混合训练，1:4 推理** | **82%** |

> 💡 **结论**：混合训练最好。单一比例上限约 79%，混合策略额外涨 3%——模型学会了在不同"latent 新鲜度"下工作，推理时更鲁棒。

## 4.3 真机实验

### 平台与任务

| 平台 | 任务数 | 任务示例 |
|------|--------|---------|
| Franka 单臂 | 4 | 擦白板、按印章、放碟子、铲鸡蛋放面包 |
| Franka 双臂 | 2 | 舀爆米花、开锅盖取玉米 |
| AgileX 移动 | 2 | 移到桌边叠盘、分类勺子放柜子 |
| 天工人形手 | 2 | 开抽屉、按按钮 |

- 每任务 200 条 tele-op demo，15 次 rollout × 3 种子

### 主要结果（Table 2）

| 方法 | Franka 均值 | AgileX | 天工人形 |
|------|------------|--------|---------|
| **LaST₀** | **72%** (±3) | **+14%** | **+14%** |
| π₀.₅ | 59% (±4) | - | - |
| SpatialVLA | 41% (±2) | - | - |
| CoT-VLA | 50% (±2) | - | - |

### 长时序任务（铲鸡蛋，连续 3 次）

| 方法 | 第 1 次 | 第 2 次 | 第 3 次 |
|------|--------|--------|--------|
| **LaST₀** | 0.66 | 0.47 | **0.33** |
| π₀.₅ | 0.47 | 0.20 | 0.07 |

> 💡 **长时序关键发现**：随着任务步骤增加，LaST₀ vs π₀.₅ 的差距越来越大（第 3 次 4.7×），说明 latent CoT 对状态一致性的维护有根本性作用。

## 注意力热力图分析（Fig. 4）

| 方法 | 注意力模式 |
|------|-----------|
| LaST₀（无 CoT） | 分散，未聚焦于操作对象 |
| CoT-VLA（显式 CoT） | 注意力在语言 token 上，物体区域弱 |
| **LaST₀（有 latent CoT）** | **高度集中在操作物体 + 机械臂区域** |

> 💡 **Latent CoT 让模型"看对了地方"**，这在定性上解释了为什么性能有提升。
