# 8. Conclusion

## 论文总结

MLLMs在跨模态理解方面取得了显著进展，但**计算效率**是关键瓶颈。

**Token压缩**是一个有前景的解决方案：
- 通过跨MLLM组件减少冗余
- 同时提升训练和推理效率
- 缓解长上下文推理的复杂度

### 领域演进轨迹

```
单模块 → 多模块协同
固定策略 → 自适应动态策略
静态图像 → 复杂视频序列
```

### 仍存在的关键挑战

1. **统一评估框架缺失**: token压缩缺乏标准化benchmark
2. **与主流训练/推理库的集成有限**: 与Flash Attention等加速库的兼容性问题
3. **与其他MLLM效率技术的协同不足**: 与量化、蒸馏等技术的结合尚待探索

### 最终愿景

> 通过战略性token压缩方法论，推进高效、可扩展、可实际部署的多模态大语言模型。

---

## 全文核心Takeaways

1. **压缩位置选择**: Vision Encoder压缩获得全链路收益，LLM压缩更灵活但仅加速后续计算，Projector是天然的压缩位置
2. **机制选择**: Merging和Dropping互补；Purely-Visual和Text-guided互补
3. **部署策略**: Plug-in适合快速部署，Re-training适合追求极致性能
4. **视频理解**: 时序压缩是独特挑战，需要spatial-temporal联合处理 + 时间结构保留
5. **开放问题**: 理论基础、自适应性、细粒度任务性能、评估标准化
