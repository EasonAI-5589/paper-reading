# 5 User Interface

## 📌 预览
Web 前端三大组件设计，确保用户在高风险 Web3 操作中保持透明度和控制权。

---

## 前端架构（Figure 8）

基于 **Vue.js** + **crypto-js** 构建，通过第三方浏览器扩展（如 MetaMask）连接用户钱包，**不直接操作用户私钥或签名**。

### 三大组件

| 组件 | 位置 | 功能 |
|------|------|------|
| **Chatbot** | 中央 | 自然语言交互入口 + prompt engineering 保持任务聚焦 |
| **Operation Log** | 左侧 | 实时展示 LLM 输出：推断意图、操作序列、参数 |
| **Operation Flow** | 右侧 | 有向图可视化执行流程，可检查/修改步骤，确认后点击执行 |

### 交互流程
1. 用户在 Chatbot 输入自然语言指令
2. Operation Log 实时显示 LLM 的推理过程
3. Operation Flow 渲染步骤为有向图节点
4. 用户检查、可选修改，点击 "play" 确认执行
5. 执行过程中高亮当前节点，实时反馈进度

> 💡 **批读**: 
> - **不直接操作私钥**是关键设计决策 — Agent 生成交易参数，用户在钱包中确认签名，保证资产安全
> - Operation Flow 的可编辑有向图设计让用户可以在执行前审查和修改步骤，这在高风险场景中非常必要
> - 但论文没有做正式的用户研究来验证 UI 设计的有效性

---

## 🔖 Section 总结

### 核心洞察
1. **Agent as mediator, not custodian** — Agent 是中介而非托管者，不触碰私钥
2. 三组件设计形成 **自然语言 → 结构化表示 → 可视化反馈** 的完整交互闭环
3. 透明性和用户控制权是高风险 AI 系统设计的核心原则
