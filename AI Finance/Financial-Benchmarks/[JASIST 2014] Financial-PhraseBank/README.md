# Financial PhraseBank

**论文**: Good Debt or Bad Debt: Detecting Semantic Orientations in Economic Texts<br>
**发表**: Journal of the Association for Information Science and Technology, 2014<br>
**arXiv**: [1307.5336](https://arxiv.org/abs/1307.5336)<br>
**数据**: [takala/financial_phrasebank](https://huggingface.co/datasets/takala/financial_phrasebank)<br>
**许可**: CC BY-NC-SA 3.0

经典英文金融情感分类数据集，包含 4,840 个由金融背景标注者判断为正面、负面或中性的句子，并按标注一致率提供多个子集。ODA-Fin-RL 将其缩写为 FPB，使用 weighted F1 评估并取得 83.4。

**已有覆盖关系**: FLUE、PIXIU、FinBen 等综合评测可能使用或改编该数据，但仓库此前没有独立条目。
