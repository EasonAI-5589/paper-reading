# FinanceBench

**论文**: FinanceBench: A New Benchmark for Financial Question Answering  
**发表**: arXiv 预印本  
**arXiv**: [2311.11944](https://arxiv.org/abs/2311.11944)  
**代码与数据**: [PatronusAI/financebench](https://github.com/PatronusAI/financebench)

面向上市公司财务文件的开放式问答 benchmark，包含答案及证据文本，用于评估检索、长上下文和回答忠实度。

> 当前仅完成基础收录。
