# FinChain

**论文**: FinChain: A Symbolic Benchmark for Verifiable Chain-of-Thought Financial Reasoning  
**发表**: arXiv 预印本  
**arXiv**: [2506.02515](https://arxiv.org/abs/2506.02515)  
**版本**: v4, 2026-04-30  
**代码**: [mbzuai-nlp/finchain](https://github.com/mbzuai-nlp/finchain)

覆盖 12 个金融领域、58 个主题的符号化 benchmark，通过参数化模板和可执行 Python trace 验证中间推理，并提出 ChainEval。
