# FinanceReasoning

**论文**: FinanceReasoning: Benchmarking Financial Numerical Reasoning More Credible, Comprehensive and Challenging  
**发表**: ACL 2025  
**arXiv**: [2506.05828](https://arxiv.org/abs/2506.05828)

整理并修正多个公开金融数值推理数据集，提供详细 Python 解答、3,133 个金融函数及 238 道困难问题。

**FinChain 关系**: 强化答案级数值可靠性，但 FinChain 指出它没有系统验证预测推理链与 gold steps 的对齐。
