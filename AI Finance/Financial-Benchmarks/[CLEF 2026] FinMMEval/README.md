# FinMMEval

**论文**: The CLEF-2026 FinMMEval Lab: Multilingual and Multimodal Evaluation of Financial AI Systems  
**发表**: CLEF 2026  
**arXiv**: [2602.10886](https://arxiv.org/abs/2602.10886)

面向金融 AI 的多语言、多模态评测框架，包含 Financial Exam Question Answering、PolyFiQA 多语言金融问答，以及 Financial Decision Making 三项任务。

**研究价值**: 可用于检查金融推理模型从单语言文本推理扩展到多语言理解、多模态证据和决策任务后的泛化能力。

> 当前仅完成基础收录。
