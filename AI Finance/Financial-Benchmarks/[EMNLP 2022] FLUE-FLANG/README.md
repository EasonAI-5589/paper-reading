# FLUE / FLANG

**论文**: When FLUE Meets FLANG: Benchmarks and Large Pre-trained Language Model for Financial Domain  
**发表**: EMNLP 2022  
**arXiv**: [2211.00083](https://arxiv.org/abs/2211.00083)

提出金融语言理解评测套件 FLUE，以及采用金融关键词掩码、span boundary 和 filing 目标预训练的 FLANG 模型。

**FinChain 关系**: 金融 NLP 综合评测背景，主要覆盖理解任务而非多步数值推理。
