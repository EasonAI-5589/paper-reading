# FinEval

**论文**: FinEval: A Chinese Financial Domain Knowledge Evaluation Benchmark for Large Language Models<br>
**发表**: arXiv 预印本<br>
**arXiv**: [2308.09975](https://arxiv.org/abs/2308.09975)<br>
**代码/数据**: [SUFE-AIFLM-Lab/FinEval](https://github.com/SUFE-AIFLM-Lab/FinEval)

中文金融综合评测。论文版本包含 8,351 道题，覆盖金融学术知识、金融行业知识、金融安全知识和金融 Agent；项目后续版本继续扩展了多模态与金融严谨性测试。ODA-Fin-RL 使用其中的中文准确率评估一般金融理解能力，并取得 77.0。

**与 ODA-Fin-RL 的关系**: 三个一般金融理解 benchmark 之一，用于检验数据中心化后训练是否提升中文专业知识和业务能力。
