# TAT-QA

**论文**: TAT-QA: A Question Answering Benchmark on a Hybrid of Tabular and Textual Content in Finance  
**发表**: ACL 2021  
**arXiv**: [2105.07624](https://arxiv.org/abs/2105.07624)  
**代码**: [NExTplusplus/TAT-QA](https://github.com/NExTplusplus/TAT-QA)

基于真实财务报告的表格与文本混合问答 benchmark，重点评估加减乘除、计数、比较和排序等数值推理能力。

> 当前仅完成基础收录。
