# MultiHiertt

**论文**: MultiHiertt: Numerical Reasoning over Multi Hierarchical Tabular and Textual Data  
**发表**: ACL 2022  
**arXiv**: [2206.01347](https://arxiv.org/abs/2206.01347)  
**代码**: [psunlpgroup/MultiHiertt](https://github.com/psunlpgroup/MultiHiertt)

面向包含多张层级表格和长文本的金融报告，评估跨表格、跨文本的复杂多步数值推理。

> 当前仅完成基础收录。
