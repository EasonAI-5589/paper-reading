# Finova

**来源论文**: Agentar-Fin-R1: Enhancing Financial Intelligence through Domain Expertise, Training Efficiency, and Advanced Reasoning<br>
**发表**: arXiv 预印本<br>
**arXiv**: [2507.16802](https://arxiv.org/abs/2507.16802)<br>
**代码/数据**: [antgroup/Finova](https://github.com/antgroup/Finova)

面向真实金融部署能力的中文 benchmark，覆盖 Agent 能力、复杂推理、安全与合规。任务包括意图识别、槽位识别、工具规划、表达生成、金融数学、代码理解和领域推理。ODA-Fin-RL 使用官方评测框架，并取得 54.6。

**与 FinChain 的区别**: FinChain 强调可执行数值推理链，Finova 更接近金融业务 Agent 与合规场景，可以评估方法是否能从计算题迁移到操作和风险约束。
