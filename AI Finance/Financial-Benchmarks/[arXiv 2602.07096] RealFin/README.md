# RealFin

**论文**: RealFin: How Well Do LLMs Reason About Finance When Users Leave Things Unsaid?  
**发表**: arXiv 预印本  
**arXiv**: [2602.07096](https://arxiv.org/abs/2602.07096)

通过从金融考试题中系统移除必要前提，评估模型是否能够识别信息不足、拒绝无依据作答，而不是强行猜测。覆盖中英文，并分别测试正常回答、缺失信息识别和拒绝错误选项。

**研究价值**: 可用于训练金融模型的 abstention / uncertainty 能力，与 FinChain 的“步骤正确性”形成互补。
