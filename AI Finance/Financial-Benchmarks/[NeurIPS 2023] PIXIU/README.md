# PIXIU

**论文**: PIXIU: A Large Language Model, Instruction Data and Evaluation Benchmark for Finance  
**发表**: NeurIPS 2023  
**arXiv**: [2306.05443](https://arxiv.org/abs/2306.05443)

集金融指令数据、FinMA 模型和标准化评测于一体，覆盖金融 NLP 与预测任务。

**FinChain 关系**: 综合金融 benchmark 背景工作，覆盖面广，但并非专门针对可验证多步推理。
