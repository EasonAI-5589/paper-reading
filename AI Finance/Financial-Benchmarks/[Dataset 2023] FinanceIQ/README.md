# FinanceIQ

**来源项目**: XuanYuan Chinese Financial Chat Model<br>
**项目**: [Duxiaoman-DI/XuanYuan](https://github.com/Duxiaoman-DI/XuanYuan/tree/main/FinanceIQ)<br>
**数据**: [Duxiaoman-DI/FinanceIQ](https://huggingface.co/datasets/Duxiaoman-DI/FinanceIQ)<br>
**许可**: CC BY-NC-SA 4.0

中文金融职业知识评测，题目来自 CPA、CFA 等专业资格考试，主要测试会计、经济学、证券分析和投资等深层领域知识。ODA-Fin-RL 将其记为 `FinIQ`，以准确率评估并取得 74.2。

**收录说明**: FinanceIQ 是公开数据集和项目 benchmark，未核实到独立 benchmark 论文，因此按 Dataset 条目收录。
