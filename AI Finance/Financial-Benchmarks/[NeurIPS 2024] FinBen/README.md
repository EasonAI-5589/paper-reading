# FinBen

**论文**: FinBen: A Holistic Financial Benchmark for Large Language Models  
**发表**: NeurIPS 2024  
**arXiv**: [2402.12659](https://arxiv.org/abs/2402.12659)

包含 36 个数据集和 24 类任务，覆盖信息抽取、文本分析、QA、生成、风险、预测、决策、Agent 与 RAG。

**FinChain 关系**: 全面金融能力评测背景，与 FinChain 聚焦单一能力“可验证符号推理”形成互补。

> 当前仅完成基础收录。
