# Trading-R1

**论文**: Trading-R1: Financial Trading with LLM Reasoning via Reinforcement Learning<br>
**发表**: arXiv 预印本<br>
**arXiv**: [2509.11420](https://arxiv.org/abs/2509.11420)<br>
**项目**: [TauricResearch/Trading-R1](https://github.com/TauricResearch/Trading-R1)<br>
**权重/数据/代码**: 截至 2026-06-15 尚未公开；项目页仍标注 “Releasing soon”

面向可解释交易决策的金融推理模型，通过 SFT 和三阶段由易到难的强化学习课程学习事实支撑的投资论点、交易规划与波动率调整决策。训练语料 Tauric-TR1-DB 包含 100K 样本，覆盖 18 个月、14 个股票和 5 类金融数据源；论文在 6 个股票与 ETF 上报告更高风险调整收益和更低回撤。

**研究价值**: 它把金融推理从考试式问答推进到可执行交易，但目前复现资产尚未发布。适合作为数据课程、风险奖励和结构化输出的设计参照，不应暂列为可直接训练基线。

> 当前仅完成基础收录。
