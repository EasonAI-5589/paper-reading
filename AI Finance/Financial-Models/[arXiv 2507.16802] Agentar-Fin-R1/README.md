# Agentar-Fin-R1

**论文**: Agentar-Fin-R1: Enhancing Financial Intelligence through Domain Expertise, Training Efficiency, and Advanced Reasoning<br>
**发表**: arXiv 预印本<br>
**arXiv**: [2507.16802](https://arxiv.org/abs/2507.16802)<br>
**基础模型**: Qwen3<br>
**规模**: 8B / 32B<br>
**数据**: [Agentar-DeepFinance-100K](https://huggingface.co/datasets/antgroup/Agentar-DeepFinance-100K)<br>
**评测**: [antgroup/Finova](https://github.com/antgroup/Finova)

强调可信金融知识工程、多智能体数据合成、难度感知优化和动态归因的金融推理模型系列。除 Fineva、FinEval、FinanceIQ、MATH-500 和 GPQA-Diamond 外，论文还提出 Finova，评估 agent-level 金融推理与合规验证。

**开放情况**: 100K 级金融 CoT 数据和 Finova benchmark 已公开；截至 2026-06-15，未在 antgroup Hugging Face 组织中检索到论文所述 8B/32B 官方模型权重。
