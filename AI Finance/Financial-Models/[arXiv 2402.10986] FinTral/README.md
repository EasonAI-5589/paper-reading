# FinTral

**论文**: FinTral: A Family of GPT-4 Level Multimodal Financial Large Language Models<br>
**发表**: arXiv 预印本<br>
**arXiv**: [2402.10986](https://arxiv.org/abs/2402.10986)<br>
**项目**: [UBC-NLP/fintral](https://github.com/UBC-NLP/fintral)<br>
**权重/完整代码**: 截至 2026-06-15 未检索到可直接复现的官方发布

基于 Mistral-7B 的多模态金融模型族，组合领域继续预训练、指令微调、RLAIF/DPO、工具调用和检索，覆盖文本、数值、表格与图像。论文同时构建了包含 9 类任务、25 个数据集的评测集合，并报告 FinTral-DPO-T&R 在零样本设置下超过 ChatGPT-3.5 的全部任务以及 GPT-4 的 5/9 类任务。

**研究价值**: FinTral 较早把领域预训练、偏好优化、多模态输入和工具检索放进统一金融模型配方。公开项目目前内容有限，因此适合作为方法和消融参照，而不是首选复现基线。
