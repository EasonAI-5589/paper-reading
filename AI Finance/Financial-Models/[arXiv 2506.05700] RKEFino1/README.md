# RKEFino1

**论文**: RKEFino1: A Regulation Knowledge-Enhanced Large Language Model<br>
**发表**: arXiv 预印本<br>
**arXiv**: [2506.05700](https://arxiv.org/abs/2506.05700)<br>
**基础模型**: Qwen2.5-14B<br>
**权重**: [YanAdjeNole/RKEFino1-14B](https://huggingface.co/YanAdjeNole/RKEFino1-14B)<br>
**许可**: Apache-2.0

面向 Digital Regulatory Reporting 的监管知识增强模型，在 Fino1 思路上加入 XBRL、Common Domain Model 和 MOF 等领域知识，覆盖知识问答、数学推理和句子/表格中的 Numerical NER。

**研究价值**: 提醒金融推理不能只优化答案正确率，还要显式处理监管知识、实体识别和合规约束。权重已公开，但未检索到完整官方训练数据。

> 当前仅完成基础收录。
