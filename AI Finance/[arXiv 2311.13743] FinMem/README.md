## 简介

FinMem 是面向金融决策的 LLM Agent 框架，由 Profiling、分层 Memory 和 Decision-making 三个核心模块组成。其记忆设计模拟交易者对不同时间尺度信息的处理，并通过可调认知跨度和角色设定改善股票交易表现。
